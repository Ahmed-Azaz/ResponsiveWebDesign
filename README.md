# Responsive Web Design

## Overview
A responsive page built with HTML and Bootstrap 5. It displays a tasbih (dhikr) layout with images, cards, and text content. The layout adapts to mobile, tablet, and desktop screen sizes.

## What it does
- Three-column layout on desktop that collapses to two columns on tablet and one on mobile
- Sidebar with images in different arrangements depending on screen size
- Cards with Arabic dhikr text
- A section showing a hadith quote with accompanying images

## Built with
- HTML
- Bootstrap 5 (via CDN)

## File structure
- `rwdtaskday3.html` - main page
- `main2.png, side*.png, bookmark.png, ...etc` - image assets

## How to run
Open `rwdtaskday3.html` in a browser. No build step or server needed.

## Notes
- Bootstrap is loaded from the jsDelivr CDN, so an internet connection is required
